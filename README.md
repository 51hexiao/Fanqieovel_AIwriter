# 番茄短故事工作台（桌面版）

本地运行的「选题 → 生成 → 质检 → 审核 → 半自动发布」桌面应用。

## 启动

双击桌面快捷方式「番茄故事工作台」，或进入 `dist/FanqieWorkbench/` 双击 `FanqieWorkbench.exe`。

- 原生窗口，无需命令行、无需装 Python；
- 数据（数据库/配置/日志）保存在 exe 同目录，整个文件夹可随意搬动；
- 首次运行如遇 SmartScreen 提示，点「更多信息 → 仍要运行」（未签名的本地程序都会这样）。

修改代码后重新打包：运行 `build_desktop.bat`（开发调试可用 `python desktop.py`，同样是原生窗口）。

## 使用流程

1. **设置**：选接口协议（OpenAI 兼容 / Gemini 原生），填 API 地址和 Key，点「获取列表」自动拉取可用模型从下拉框选（也可手动输入）；Key 支持显示/隐藏。连不上或鉴权失败都会给出具体原因。接口报参数错误时展开「兼容选项」（如不发送 max_tokens）。API Key、稿件库、浏览器登录状态都保存在 exe 同目录，重新打包会自动备份还原。
2. **选题库**：两种选题来源随你用——「随机生成」纯组合出新；自己想到的点子直接在输入框录入。所有选题永久留存，按 全部/未用/已用 筛选，写过的自动标记并避开重复题材和人名。**组合骨架 = 番茄官方分类**：五个维度词表（主分类/情节/角色/情绪/背景，共 100+ 标签）与发布页分类面板一字不差，随机组合从中按线抽签——🗡无脑爽文线（内部键"悬疑"） 主分类×情节×背景×情绪 + 手艺维度 人设×底牌，遵循爽文演化规律：前半憋屈让读者受、主角清醒或无欲无求不内耗，后半反击爽、最终胜利属于主角；🏮细腻写实线（内部键"温情"） 主分类×情节×情绪 + 手艺维度 情感内核×设定（写实为底，允许极轻梦幻点缀）×核心意象；官方「角色」标签作为人设参考注入选题提示词。选好风格线再点「随机生成 6 个」，一次出一条线的选题；稿件的风格线决定大纲、写作与审稿提示词。挑一篇 →「就写这篇」，后台自动大纲＋分节写完约 6500 字（5-10 分钟）。番茄改版后，到「设置 → 🍅 番茄官方分类词表」把新的分类面板整段粘进去解析保存即可（等价于改 exe 同目录 `categories.json`：认得出的词自动归维度，预览标绿新增/标黄减少，未识别的不会保存；「恢复内置词表」一键还原）。稿件编辑器顶部会显示该稿的「发布主分类」建议，发布时照着选。
3. **稿件库**：打开稿件 → 本地质检 / AI 逻辑审查 / 润色去AI味 → 手动修改 → 「批准入库」（自动登记人名，防止后续撞名）。爽文线内置「爽感法则」：开篇三行砸受屈场面、每节一次打脸、断章吊在打脸/揭晓前、底牌规则全文一致；细腻写实线内置「情绪法则」：意象复现三次、情绪延迟、禁止升华句、断章情绪钩。AI 审稿按线评分：爽文线查爽点密度与底牌一致性，写实线查真挚度与煽情。
4. **拆解库**：刷到爆款短故事就粘进来（标题 + 正文 + 所在线），AI 自动拆成结构零件：标题句式、开篇逐句拆解、各节断章钩类型、反转位置、可抄技巧。攒够 2 篇以上点「生成共性报告」，提炼标题句式榜、开篇套路榜和可直接执行的规则。**拆解库会自动反哺写作**：生成选题时带上同线爆款的标题句式做参照（只学结构，禁止抄情节），写大纲时带上爆款开篇写法。样本越多，生成越对味。番茄短故事网页端没有阅读入口，链接直抓不可行；已预留信息源口子：`ingest.py` 的 `fetch()` 加后端 `/api/bench/import`，以后换任何能拿到正文的信息源（其他平台 / 截图 OCR / 文件导入），实现一个函数就能自动进拆解流程，现阶段照旧手动粘贴。
5. **发布助手**（稿件页底部）：点「自动填入草稿」一条龙——自动打开番茄后台 → 点「新建短故事」→ 填入标题 → 粘贴正文 → 点「存草稿」。首次使用需在弹出的浏览器里扫码登录，之后免登录。草稿存好后，在浏览器里设置封面、作品分类，**人工点「下一步」发布**，回工作台点「标记已发布」留档。「复制标题 / 复制正文」按钮仅作自动流程失败时的备用。

## 每天的节奏建议

每天按线各点一次「随机生成 6 个」（爽文线、写实线各来一轮），写 2-3 篇（建议 2 爽文 + 1 写实），审核通过后错峰发布。系统自动避开最近 30 个用过的题材组合和已用过的核心人名。

## 文件说明

| 文件 | 作用 |
|---|---|
| `desktop.py` | 桌面窗口入口（pywebview） |
| `app.py` | 后端服务（被 desktop.py 加载，不单独运行） |
| `build_desktop.bat` | 一键打包 exe |
| `config.json` | 配置（含 API Key，勿外传） |
| `data.db` | 稿件库（SQLite，含发布记录） |
| `sensitive.txt` | 可选，每行一个自定义敏感词 |
| `selectors.json` | 可选，配置后自动填入番茄后台 |
| `browser_profile/` | 发布浏览器的登录状态 |

`selectors.json` 为**可选覆盖项**：程序默认按按钮文字定位（「新建短故事」「请输入短故事名称」占位符、页面中最高的正文编辑区、「存草稿」按钮），页面改版导致定位失败时才需要手动指定 CSS 选择器：

```json
{
  "new_story_button": "新建短故事入口的选择器",
  "title_input": "标题输入框的选择器",
  "editor": "正文编辑器的选择器",
  "save_draft": "存草稿按钮的选择器"
}
```

发布自动化基于 playwright：exe 内已打包驱动；浏览器优先用内置 Chromium，找不到时自动改用系统 Edge（Windows 自带，无需额外安装）。
